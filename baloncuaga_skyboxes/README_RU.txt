НЕБО baLONCUaga

Шесть оригинальных наборов: Солнечное небо, 3XL в небе, Закат,
Пасмурное небо, Северное сияние и Космос.

В каждом каталоге находятся шесть граней неба 1024 x 1024:
rt.tga, bk.tga, lf.tga, ft.tga, up.tga, dn.tga.
preview.tga — панорамная миниатюра 512 x 256 для выбора в меню.
Формат всех изображений: несжатый 24-битный TGA.

Сохраните структуру baloncuaga_skyboxes рядом с hl.exe.
Наборы выбираются в разделе неба BALONCUAGA. Исходные файлы карт
и стандартные текстуры игры не изменяются.

Небо и звёзды созданы процедурно. Эмблема 3XL в ночном варианте
сгенерирована встроенным image_gen; исходный PNG включён в SOURCES.
Смежные грани и угловые пиксели согласованы. Использована родная
ориентация неба GoldSrc, а не произвольный порядок граней куба.

Права на сгенерированные изображения переданы в общественное
достояние по CC0 1.0 Universal. Разрешены использование, изменение
и распространение, в том числе коммерческое, без указания автора.
https://creativecommons.org/publicdomain/zero/1.0/

Воспроизводимый генератор находится в artwork/generate_skyboxes.py.
Он требует Python 3, NumPy и Pillow. Запуск из каталога сборки:
  python artwork/generate_skyboxes.py
Отдельный набор:
  python artwork/generate_skyboxes.py --only night
Размер 512 для облегчённого полного набора:
  python artwork/generate_skyboxes.py --size 512

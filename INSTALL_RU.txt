УСТАНОВКА ИЗ ОДНОЙ ASI

1. Полностью закрой CS.
2. Сохрани старый CS16Customizer.asi вне папки игры.
3. Скопируй новый CS16Customizer.asi рядом с hl.exe. Оставь одну копию;
   прежнюю копию из scripts при наличии перенеси в резервную папку вне игры.
4. Запусти CS. ASI создаст необходимые папки, установит встроенные модели
   и ресурсы. Заменяемые файлы попадут в .baloncuaga-install/backups.
5. После сообщения об установке перезапусти игру один раз: штатные окна
   и TAB читают свои ресурсы при запуске. В первом сеансе хуки не включаются.
   При следующих запусках совпадающие файлы не заменяются.

ASI-загрузчик уже должен быть установлен: version.dll рядом с hl.exe,
загрузка ASI из корня разрешена. Сам по себе GoldSrc файлы .asi не запускает.
Загрузчик нельзя установить самим ASI до его первой загрузки.

TAB снова штатный: оригинальная раскладка, обычный фон, исходные шрифты.
Другие функции, оформление HP и меню сохраняются.

Установщик обслуживает только встроенный список из 120 файлов. INI, история,
профили, глобальные настройки загрузчика и свои модели не перезаписываются.
Папки для своих моделей: cstrike/models/customizer/{knife,he,flash,smoke}.
Скайбоксы читаются непосредственно из ASI. Исходники в игру не нужны.

При ошибке записи установка прекращается; уже изменённые файлы откатываются.
Прежние файлы сохраняются в резервной папке. Проверь доступ к каталогу игры
перед повтором. Причина ошибки записывается в CS16Customizer.log.

Проверено автономно, без установки в запущенную игру. CHECKS_RU.txt содержит
перечень проверок и их ограничения.
